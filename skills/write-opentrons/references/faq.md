# 高频问题问答

用于帮助AI向用户解释已有规则、机制与设计原因。根据本次问题查找匹配条目；问法与要点提供解释灵感，可按用户背景自由选择、组合和改写，不限定句式、篇幅或排版。未命中时按问题区分依据：项目默认、现场经验或本次设计取舍回查对应规则及已确认来源；涉及官方机制、API或硬件能力时查相关官方文档或源码并核对设备与版本。混合问题分别说明两类依据；来源未能支持的原因或效果保留未决，不把项目选择说成官方要求。

## 条目组织

以下结构用于条目维护与检索，必要时注明适用条件；用户答复按本次需要自然组织。

- 常见问法：用户通常怎样提出这个问题，可保留含义相同的问法。
- 解释要点：帮助用户理解原因、含义或取舍的关键内容。
- 依据出处：指向支持解释的官方资料或现有规则、API、经验条目。

补充维护（仅添加或修改问答时）：先按问题含义查重，同义问法并入原条目，新解释优先补充原条目，确有独立问题再新增。口述先归纳、筛选和压缩，只保留有助理解且有依据的要点，省去重复、离题或无新增价值的内容；经验目的与已证实效果分开，涉及执行要求仍回查原规则。更新后简查含义、重复与冲突、依据及链接，项目级检查沿用[项目维护规则](project-maintenance.md)。
