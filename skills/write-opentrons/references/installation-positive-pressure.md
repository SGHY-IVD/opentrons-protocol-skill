# 第三方扩展：正压模块（用户提供过滤案例）

查用前应用[统一安装核验](installation-core.md#统一安装核验)；这里只维护本对象的承载表达、案例配置及具体证据缺口。
来源：用户提供的正压过滤程序，SHA-256 625bcbcdd06a46650d457f4eb767e0263cad52188116a63d152d5aff33cdf098；是案例安装与搬运记录，不是官方fixture/shared-data关系或厂商兼容认证。
物理关系：实际安装支撑/扩展承载区域 -> 正压模块 -> 本次匹配的过滤/接收组合耗材。案例将“深孔板+过滤板组合体”作为一个整体搬入、搬出；真实分层、密封和夹持对象按实际装配核对，不凭一个Labware标签推导完整几何。组合体与模块是上下层承载关系，移出组合体后模块本体仍占原安装区域。
软件表达：用PPMDevice(protocol)创建控制对象，不调用虚构的官方load_module型号；组合体以原生Labware及普通move_labware登记位置，无额外的正压模块坐标模型或官方引擎占位。实际模块本体和运动包络仍记入布局账本；官方模拟不能因此识别其完整体积。
案例配置：正压交互位B4，组合体原位置C1；正压侧抓手取/放偏移均为x=0、y=0、z=+5mm，相对普通台面侧取/放均为0。明确复用同一安装、组合体及坐标基准时可沿用；不是全体正压设备的默认位置、模块高度或通用抓手补偿。其他安装和耗材须核对本次适用性；第4列的移液可达性按统一规则判断。
耗材证据：案例用nest_96_wellplate_2ml_deep登记整个组合体，另加载热震荡深孔板适配器；这不能证明标准NEST定义已描述实际过滤板上层、组合体总高、夹持点或体积模型，也不能认定任意过滤板都适配。实际组合耗材定义未提供，按本次任务补齐或核对，不能把该代理名称收为通用兼容白名单。
安装缺口：厂家型号、底层夹具/cutout适配、固定朝向、模块运动与邻位包络及真实组合耗材尺寸未从源程序确定；保留具体缺口，不推定与其他模块共享安装关系。机制/动作条件查module-conditions同名节，接口和使用片段分别查api-module-positive-pressure与module-practices。
