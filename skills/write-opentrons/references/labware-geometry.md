# 耗材几何与深耗材定位

仅在定义身份、液面模型、沿壁或特殊位置需要实际几何，或深耗材需要下探粗筛时读取相关章节。体积与路径通用规则见[操作规则](operations.md)，关键定位确认见[主动确认](protocol-interaction.md#主动确认按影响筛选)。

## 官方耗材的定位与证据

官方耗材先查[名称入口](catalog.txt)的常用项，未命中按该入口检索Flex范围发布索引并核对实际定义；常用表缺项不阻塞官方耗材查找，也不直接转为自定义创建。索引命中不证明软件可用或安装兼容。按本文件“耗材几何按需查询”获取当前任务所需的官方定义，不必再请求联网许可；自定义schema/定义及厂家尺寸按[自定义耗材分支](custom-labware.md)查询。机器人软件/API映射超出维护范围时按[版本索引](api-versions.md#编写前的版本选择与环境核对)定向核对官方，不因此升级接口基线。

## 深耗材的枪头长度粗筛

仅用于触发[生成前确认](protocol-interaction.md#主动确认按影响筛选)，不是碰撞模型或安全下探限值。官方Flex枪头定义快照（2026-10-21核对，commit `72fd2310e5b8f39e6024f3926c95bfc4468be260`，schema 2、定义version 1）：

|枪头规格µL|官方tipLength总长mm|定义tipOverlap重叠量mm|两者之差：粗筛参考mm|下探深度提醒阈值mm|
|---|---|---|---|---|
|20|52.0|10.5|41.5|36.5|
|50|57.9|10.5|47.4|42.4|
|200|58.35|10.5|47.85|42.85|
|1000|95.6|10.5|85.1|80.1|

来源：[官方耗材定义目录](https://github.com/Opentrons/opentrons/tree/72fd2310e5b8f39e6024f3926c95bfc4468be260/shared-data/labware/definitions/2)，文件为`opentrons_flex_96_tiprack_{20,50,200,1000}ul/1.json`及对应`opentrons_flex_96_filtertiprack_*`；已核对普通/滤芯版本两字段一致。仅适用这组定义，不推广到第三方或自定义枪头。定义重叠量不代表所有实际取头配置：移液器硬件版本及喷嘴布局可能另有tipOverlaps；疑难时按[官方仓库导航](upstream-maintenance.md#特殊问题查找导航)核对，不为日常提醒展开全部配置。

生成阶段粗筛：孔深为D、目标尖端高度为距孔底z时，孔口以下下探深度为D−z；吸液过程中位置变化时取最深点，不只看起点，也不只比较耗材总深度。达到或超过表中阈值即触发深管确认；阈值为粗筛参考减5mm，5mm是项目提醒余量，可按本次明确要求覆盖，不是官方安全距离。源孔深度/位置未知且属于明显深管时直接反馈缺口，不猜尺寸；动态跟随或探测的最深位置未知时先确认允许范围。

该比较不直接改变吸液位置，不自动打开探测。未触发也不证明安全；高液面导致浸没过深、管架/管口与机身干涉等已有风险仍独立触发确认。单通道及多通道单喷嘴均不能凭表判定可到底。已确认当前配置与操作范围时复用结论；用户选择探测等方案后复用既有原子规则，不另建深管流程。上述计算只用于生成前筛选，无需给交付协议增加检查器或parameter。

## 耗材几何按需查询

不另建全量几何库或手工重复尺寸表；名称索引按catalog检索。需要核对定义身份、液面/体积换算模型、沿壁偏移、特殊位置、槽内居中等时，先复用本次用户提供的实际定义或已获取且匹配的官方定义；缺少时允许直接查询 `https://github.com/Opentrons/opentrons` 的 `shared-data/labware/definitions/`，按确切namespace/load_name定位并读取完整JSON，不以搜索摘要或同名近似产品代替。只获取当前任务需要的耗材，不批量同步官方库，不为普通默认位置无差别联网。

仅提取所需字段：目标孔shape、diameter或xDimension/yDimension、depth、孔位坐标、容量；需要时读取体积—高度/内壁几何模型、ordering和定位quirks。不假定所有孔完全相同，也不把容量反推成几何模型。核对定义中的loadName、namespace及version与实际选用耗材一致。

用户提供的自定义JSON或明确指定定义版本优先；未指定时获取官方当前发布的定义并记录来源版本，开发分支新增/修改但运行环境未必具备的定义不得直接当作可加载。定义版本只用于追溯和匹配，不当作不同实物型号，也不维护重复几何表。已有协议明确使用旧定义时沿用该定义；不能以新定义尺寸替换而不核对差异。运行环境实际定义不明且相关差异影响定位时，指出具体不确定性。

在任务记录中保留来源URL、定义版本及获取日期；涉及几何决策时交付简述依据，不把全部JSON贴到聊天。相同定义及已有适用模型核对记录本轮复用；保留原始JSON供本任务复用，不因一次查询自动升级技能或写入永久耗材库。以后只有定义改变、用户要求更新或发现具体差异才重新核对，不另建版本选择流程。

此例外补充本次候选/选定耗材的确切定义，不授权联网猜补API、硬件型号、安装兼容关系或自动更新全量索引。官方未找到、网络失败或定义缺少所需截面时，反馈具体缺失；有匹配的既有资料可继续使用，不凭常见尺寸猜填。孔几何与枪头/机身完整碰撞空间不同，几何数据齐全也不等于实机碰撞验证完成。
