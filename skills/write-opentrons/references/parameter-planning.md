# 参数化与派生计算

仅在参数/CSV影响实际动作数值或方案时按需读取。常规已知输入仍优先生成定值，不因此新增参数、计算函数或方案对象。本文件只维护输入绑定与生成策略；参数声明/读取契约见[参数API](api-parameters-csv.md)，流速数据与计算语义见[rates](rates.md)，混匀、分段及其他动作规则仍由[operations](operations.md)维护。

## 按实际收益选择表达方式

AI根据本次输入规模、可读性、依赖、计算复杂度和验证负担选择方案，不按是否存在parameter或是否为小数机械决定，也不强制所有脚本采用同一结构。

|情况|可采用的方式|
|---|---|
|动作数值已知，或规则在整个允许域确为恒定|生成定值；次数/样本数仅控制循环时复用已有数值|
|少量明确选项或适合维护的有限取值|生成小型映射；按实际动作体积去重，不必枚举所有参数的笛卡尔积|
|范围较大、连续体积、运行时CSV或派生关系使枚举笨重|保留必要的确定性计算及本次所需数据，输入确定后求实际值；已有CSV也可按真实数据预计算|

没有必须转为运行时计算的规模阈值。不同形式最终应得到符合相同业务规则的动作和状态；计算方式本身不构成通过或失败依据。默认不舍入输入、不改变实际体积、不以默认值回退；明确的用户覆盖按原规则核对适用范围。

## 追踪输入与派生依赖

先识别哪些量真正可变、哪些已固定，以及每个输入影响的动作。按相关业务规则同步得到实际转移量、混匀量/保留量/往返量、容量截断、分段主体/末段、批次实际吸入量及相应吸排流速；不得只根据参数默认值赋一套速度，也不能将未拆分体积的速度套给拆分后动作。正常/用水分支的液体选择按rates执行，未受输入影响的等待或位置等不重复建表。参数实际生效值仍按相关业务分支确定；仅提供字段不代表已明确覆盖该分支的默认策略。

喷嘴布局、源/目标孔或槽随输入变化时，按operations的逐物理孔账本一并更新有效喷嘴数 n；依赖 n 的瞬时供液、接收容量及位置用各孔合计量，吸排命令及流速仍使用每喷嘴实际量。不能用默认布局的 n 校验所有分支。

模式、路径等参数只绑定已明确的业务规则与分支，不在本文件重新定义混匀模式、硬件能力、几何模型或动作阈值。实际位置随液量变化时继续使用已确认的模型/API及状态账本，不自行猜算未维护的几何关系。

## 计算与执行边界

生成时确认规则、数据来源、硬件/模式与输入支持范围，选择合适的表达方式。可预见的输入与派生组合校验在本次首个取头、实际搬运或液体动作前完成。若此前已有依赖输入或会改变样品状态的模块动作（如对已装样品升温、振荡或启动PCR），校验须在该动作前完成；为解析孔位而加载耗材、加载空模块或只读状态可先进行。运行时CSV须检查完整实际数据，不只检查首行、默认值或分析占位数据。超范围、非有限数值、缺少适用规则或派生动作不合法时报告具体参数/行号及原因，不先执行部分数据再发现缺口。

CSV数值先按原始文本核对范围、整数性及所支持精度，再转换执行类型；避免浮点转换吞掉越界小数或改变阈值分支。精度受限时明确拒绝，不静默取整。

必要的数值辅助函数不含移液/搬运动作，只处理已明确的计算。业务动作仍按原子规则组织；不强制类、函数名、表结构、预检函数或方案对象。运行中的液量、位置及模块状态按真实执行路径更新，不要求将依赖运行状态的每个位置提前展开为常量。

## 自包含交付与验证

脚本只包含本次配置及可能运行分支所需的数据和必要算法；不得依赖技能目录、生成工具、外部速率文件或联网查值。数据来源与版本可追溯；内嵌数据是本次快照，不会随技能更新自动刷新。流速计算可复用rates指向的已验证纯函数，或采用已核对结果及边界等价的实现。

按实际收益和风险核对代表值、边界、派生量、阈值两侧及相关分支，可结合不变量验证，不强制穷举连续域或所有参数组合。算法、查表和定值均须覆盖实际支持域；不能以函数通过、某个默认值通过或代码较短代替完整动作/状态一致性检查。审查入口见[protocol-review](protocol-review.md)。
