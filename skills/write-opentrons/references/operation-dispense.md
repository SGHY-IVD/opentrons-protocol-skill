# 排空、常规移液与液体移除

按本次排液动作读取对应小节：非零push_out且体积超过阈值时查分段排空；常规移液查骨架；移除液体查已指定去向。各维度与跨维度条件仍以[操作规则](operations.md)为依据，流速和等待分别查[rates](rates.md)和[delays](delays.md)。

## 分段排空
先按组合校验确定原排液的push_out，生成时落实拆段及必要分支，参数化数值按参数化指引处理；审查只验证，不把流程生成留到审查阶段。原push_out非零且原体积V严格超过下表阈值才拆分；等于阈值、push_out=0或20µL枪头均不拆。适用于常规排空和混匀最后一次（含N=1），不额外增加混匀轮次或吸液。

|移液器|枪头容量|V阈值（µL）|末段T（µL）|
|---|---|---|---|
|50µL单/八通道|50µL|10|3|
|1000µL单/八通道、96通道200/1000µL|50µL|10|5|
|已收录适配型号|200µL|20|10|
|1000µL单/八通道|1000µL|50|20|
|96通道1000µL|1000µL|50|10|

- 主体排V−T、push_out=0；末段排T、保留原push_out。两段各按实际排量查询流速，dry_run两段同样使用水相速率。无覆盖数据报缺失，不外推；不保证末段速率一定低于主体，不自行改曲线。
- 中间等待默认0.2秒，替代主体排后等待，不叠加；末段后保留正常排后等待。中间不额外入液、退液或准备活塞。
- 常规meniscus动态路径两段均沿用dynamic。显式液面终点路径默认主体end_location=well.meniscus(z=0,target="end")；主体完成后，末段location=well.meniscus(z=0,target="start")，end_location=well.meniscus(z=0,target="end")。以纯液体为例，F 是该物理孔的最终总液量，T 是每喷嘴末段量；中间/末点为 F−n×T / F。独立板孔各取 n=1，多个喷嘴共用同一槽时按该槽的 n 核对。API 的 volume 和流速仍按每喷嘴给定，不乘 n。明确按体积换算时传逐孔总量，使用 meniscus 时不二次手动放大命令体积。第一段保留原起点，混匀从bottom(0.8)起步；第二段从实际中间点连续排，不能重置到底部。明确要求按体积指定位置时保留height_from_volume方案。
- 无模型或用户指定非液面终点时，不套液面中间点换算。保持已确认的固定位置；若为显式移动路径但中间点无法确定，先确认该点，不擅自推算几何或改变原终点。所有点仍需合法可达；不能仅因有模型就认定安全。
- 本规则拆分的是排液量，T不是push_out体积，也不是混匀保留量；最终非零push_out后只标记待准备，下一次吸液前再按原规则处理。

## 常规移液骨架

骨架：源top→必要的prepare_to_aspirate→控速入液→delay→吸液→delay→控速退出至源top→目标top→控速进入排液起点→排液。保留受控移动，不作为冗余删除。

## 移除液体的去向

移除液体统一按“吸走→退出源孔top→排入指定废液位置→处理枪头”组装。目标API支持且使用已加载垃圾桶时，以TrashBin作为dispense位置；2.15无此对象，原操作若需该接口则报告具体版本缺口；分液槽/废液孔使用指定Location。生成时确定去向、体积、速度和接收容量，push_out遵守统一规则；不为垃圾桶单设带液弃头分支，也不自动增加blow_out。返回/弃头逻辑独立，在液体排出后按既有规则执行。
