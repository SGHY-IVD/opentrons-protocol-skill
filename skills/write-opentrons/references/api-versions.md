## 选择与检查

- 新建协议先按下节完成“机器人支持范围→目标API选择→本地模拟环境”。用户已明确指定apiLevel时复用，仅核对实际接口版本及机器人兼容性；不能以本地环境或文档基线替代用户目标。
- 修改已有协议：未要求升级时保留文件原有apiLevel；不能因最新基线变化默默升级客户脚本。用户本次明确指定版本优先。
- 支持判断分为“已核对支持”“已知不支持”“资料不足”。当前基线签名含某参数，不代表旧版本也支持；没有写最低版本也不等于所有旧版本支持。
- 对不支持项定位到具体命令/参数/最低版本；先完成可独立的部分，集中反馈真正受影响的选择。不静默提高apiLevel、不偷偷换高级命令或改变物理行为。只有已收录且保持用户意图的兼容写法才可采用，并交付说明；会改变既定规则的替代需用户明确选择。
- 用户指定高于已维护基线时说明资料范围；未经明确升级不联网猜补。声明apiLevel也不证明设备软件支持，实际软件兼容未知时单独说明，不假定。
- 版本选择是一次任务级判断；对相同接口/参数组合核对一次即可，只有目标版本或用法变化才重查。按版本号元组比较，不把2.9当成大于2.30的字符串/小数。

## 编写前的版本选择与环境核对

把本节结果并入现有硬件/方案回显，集中处理当前缺口，不另起一套逐项问答。相同任务已取得的软件信息、目标选择和环境检测直接复用；环境或目标变更才重新核对。纯非行为编辑或用户明确限定本次检查范围时，只检查相关影响并如实报告。

1. **先核对机器人。** 优先取得实际机器人平台及其最高支持API；在首次硬件描述示例中引导用户一并写出机器人软件版本，不要求新用户理解或填写API。用户只知道设备软件版本时，按下表核对。不要拿电脑App版本或pip包版本当机器人软件。可提示在Opentrons App连接的机器人下查看 Robot Settings > Advanced 的最高API；路径随版本不同而异，未显示时提供机器人软件版本文字即可。数据缺失不猜“8.x”等范围。
2. **复述时告知目标API。** 根据已核实的机器人信息，告知最高支持API，并采用该上限在技能已维护范围内的版本编写，不再要求普通用户选API。用户明确指定旧API或既有脚本目标时保留；不取本地模拟器上限替代机器人上限。设备上限高于维护基线时，分别说明真实上限和技能维护基线2.30，建议采用2.30并请用户确认这一资料范围差异；不把基线说成设备最高或全部协议已实机验证，也不宣称未维护接口可用。已有明确选择则复用。核对实际用法最低版本；目标太低时说明具体冲突，不能只改声明。机器人范围未知但有明确指定目标时，可写条件稿并保留实机兼容未决；两者都未给时先引导取得机器人软件版本或其显示的支持上限，不静默回退2.30。仅用户明确授权以基线作条件方案时可用2.30，并标明适用条件。
3. **目标确定后检查模拟环境。** 用当前可执行Python运行技能根目录下的 `scripts/check_environment.py`，或复用同范围的真实检测结果。只读取包版本、SDK最高API与模拟入口帮助，不安装、不联网扫描、不连接机器人。报告被检测的解释器及环境范围；云端/沙箱结果不等于用户电脑。无法访问用户电脑时说明边界，可请其在指定Python环境运行检测并提供结果，不猜用户是否安装。
4. **按结果说明下一步。** 检测到opentrons时分别报告软件包版本、成功读取的最高API及模拟入口能否启动；包存在但导入/帮助失败不称环境可用，读取不到上限就报未知。PATH入口可能来自另一解释器，不能将当前Python的包版本/API上限归给该入口。模拟器支持目标时后续对最终代码模拟；版本不足时保留已选目标，提供安装/升级匹配模拟环境或不做本地模拟的选择，不偷偷降级交付文件。
5. **安装可选。** 未安装、无法运行或版本不足时，用通俗语言说明本地模拟不必连接机器人，可提前发现部分代码/API/耗材和执行分析错误，但不验证真实移液精度或机械位置。只在用户选择安装/升级后引导或执行：先核对操作系统、Python及所选发行版兼容要求，优先独立虚拟环境，使用该解释器的 `python -m pip`；不默认改全局环境、自动装最新版或升级机器人软件。安装后重测包、SDK上限及模拟入口。用户不安装时照已确认目标编写，如实标记未运行官方模拟；不反复劝装。用户此前已拒绝安装时直接复用选择。

检测是环境可用性检查，`--help`成功不是协议模拟通过；实际最终文件验证仍归protocol-review。若没有可执行环境，只报告无法检测，不能声称“未安装”。辅助脚本不随生成协议发送到机器人。

## 维护与交付

升级基线时更新本文件维护值、SKILL.md基线说明及真正变化的API条目；旧分界继续保留，不复制整库。参数/返回值/行为发生变化时在原API条目维护，此处只加索引。单次用户选旧版本不改变全局默认。
交付脚本写实际apiLevel，说明中简述“目标API版本、是否沿用/明确指定、具体兼容调整或未决项”；纯小改且版本未变时不重复长报告。
