# 一吸多分策略

仅在本次明确采用一吸多分时读取。通用液量、容量、路径、活塞及push_out条件仍以[操作规则](operations.md)为依据，流速与等待分别查[rates](rates.md)和[delays](delays.md)。

## 一吸多分

仅明确采用一吸多分时启用；用一次aspirate和多次原子dispense组装，不自动把普通一吸一排改成分液。下表按实际枪头规格、每通道体积维护，不按移液器标称量程或本次吸液量选行。

|枪头容量µL|首段回排量µL|尾液保留量µL|满容量时有效分液量µL|
|---|---|---|---|
|1000|40|40|920|
|200|10|10|180|
|50|5|5|40|
|20|2|2|16|

本批实际吸液量=本批各目标分液量之和+首段回排量+尾液保留量，不默认吸满。按业务顺序及单次分液量安排批次；有效预算=当前枪头/移液器模式允许容量减去首尾量，表中有效量只适用于可用满容量且起始空枪头。不要擅自把单个目标分成多次加液来凑批；若业务允许拆分则按要求处理。已有尾液/空气时额外计入容量，不直接重复套空枪头计算；跨批保留或清理尾液须按当次明确策略处理。
首段固定向源孔原位回排，不作为去向选择或询问项。吸液后保留现有吸后等待，然后在吸液结束的实际位置原位排出首段，不先退出、不横移、不改为默认动态排液；显式使用该实际Location（动态吸液或实测场景须取得真实结束位置，不能重新套旧起点）。更新源孔液量账本；初始供液需覆盖瞬时整批吸入量，不能只按最终净消耗计算。首段回排后执行现有排后等待，再按原有控速撤离与撤离后等待离开源孔。
吸液流速按整批实际吸入量查；首段及各目标排液流速按各次实际排出量查现有排液表，不改用官方multiDispense流速曲线。等待沿用delays.md；本策略的排液等待使用multi_dispense路由，实际入液/撤离才执行对应阶段，不因首段原位排液重复插入入液动作。移动速度和目标孔排液位置继续引用现有规则。
首段及所有目标排液后仍有液体（包括最后目标之后的尾部保留量），因此按[统一条件](operations.md#非零push_out活塞液量--排液终点)push_out=0。尾液不额外送入最后目标；其最终去向按本次流程明确。尾液选择回源时显式push_out=0，不因排空且终点位于弯月面0处而自动启用非零值；其他去向按统一条件判断push_out。处理后按统一规则核对活塞准备和枪头去向。未指定尾液去向或跨批复用方式时只反馈这部分缺口，不擅自回源、弃去或带入下一批。用户指定首尾量时覆盖对应默认，并重新校验容量及排净条件。
