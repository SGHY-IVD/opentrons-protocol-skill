# 手写混匀策略

仅在本次包含混匀时读取。通用账本、容量、位置、活塞与组合条件见[操作规则](operations.md)；加液后立即混匀另按[连续原位混匀](operations.md#连续原位混匀枪头连续性--位置--模式准备需求)判定衔接。

## 手写混匀

默认混匀体积M=开始混匀时孔内总液量的70%，取当前可用容量上限；容量同时受枪头、选定移液器模式限制，已有保留液另计。截断时交付说明原计算量、限制和最终量。用户指定优先。M 是每喷嘴一次吸量，不是整个共享孔同时取走的量；标准70%例适用于每喷嘴各操作一个孔。多个喷嘴同入一孔时须明确该场景混匀量口径（明确每喷嘴量，或明确整孔合计量后再按 n 换算），不自行推定新的共享混匀比例；已有明确选择不重问。按每喷嘴容量及该孔瞬时最低液量 F−n×M 核对，库存/浸没不足时报告，不静默缩量。
进入标准片段时枪头无余液。保留量R=0.1M，往返量S=0.9M；计算时机与表达方式按参数化指引选择，不改变本节比例。N为正整数，首次加液不计入N。逐步校验实际吸排量（M及确实执行的S）的可移液下限与流速表覆盖；即使M有效，S也可能低于下限，遇到时报告具体缺项，不擅改保留比例或外推速度。
N>=2：第1轮吸M、排S；第2至N-1轮吸S、排S；第N轮吸S、排M，排净包含R。N=1只吸M、排M，不预吸保留液或加额外轮次。轮次与体积共用，位置按下面两模式分别实例化；普通轮次之间不抬出孔外、不调用活塞准备。

### 模式选择

默认采用动态混匀，不再按孔深、装液比例或混匀量占比切换模式。仅在用户明确要求静态/固定位置混匀时采用静态，按已明确的范围执行。明确的位置或轨迹覆盖仍按其范围优先；单个动作的位置覆盖不自动变成整个混匀模式的切换。

不为选择模式额外索取孔深/容量或计算占比，不默认要求用户二选一或新增运行模式参数。F、容量后的M及实际孔定义仍按体积、容量、液量模型与路径需要独立核对；默认模式不能放行越界液量或不可达位置。缺模型按[液量模型核对与缺失处理](operations.md#液量模型核对与缺失处理)；液面偏移或路径不合法时报告具体缺口，不静默改用静态。交付简短说明本次采用的模式；该默认是技能策略，不是官方安全或效果保证。

### 两种执行路径与共用末排

- 固定位置：各次吸液及非末次排液均用bottom(0.8)。
- 动态：独立混匀首次从孔外进入时，在孔顶完成所需准备，控速到 `well.meniscus(z=-0.5, target="start")` 并执行入液等待，再开始首轮吸液。所有吸液（含最后一轮）使用well.meniscus(z=-0.5,target="dynamic")，按本次开始/结束液面下0.5mm联动；非末次排液从bottom(0.8)起，end_location=well.meniscus(z=-0.5,target="end")。普通排后该物理孔的总量为 F−n×R，独立板孔 n=1；不能误用完整 F 或把每喷嘴 R 当作共享孔的合计保留量。吸液结束后同孔移至排液起点，不额外退出/准备或重复入液等待。
- 共用末次排液（N=1亦同）：从bottom(0.8)起，end_location=well.meniscus(z=0,target="end")，边排边移动到排完后的液面0；不能提前到液面再排。最终孔内总量包含返回的R，纯混匀恢复F，不能用M代替。最后一次吸液仍按所选模式，只有排液收尾共用。收尾push_out仍按[非零push_out](operations.md#非零push_out活塞液量--排液终点)条件判断；满足[分段排空](operation-dispense.md#分段排空)时仅将末次排M拆段，沿用其默认液面终点与连续路径，不另设混匀专用push_out或末段量。

上述两模式的液面路径都以已初始化液量和有效模型为前提；已明确确认无模型固定方案时，由[空间层对应分支](operations.md#液量模型核对与缺失处理)覆盖位置，体积和轮次仍按本节处理。按每个动作更新/核对孔内与枪头液量。动态路径的每次起终点及最深位置均须合法，液面下偏移低于允许底部范围时不静默夹到边界。API按模型液面的起终点同步移动，不是持续实测；曲底非线性区间不宣称全程精确恒定浸深。明确按体积指定的位置保留height_from_volume，不把默认写法当成接口禁令。模式/轨迹归本节，参数化任务仅按parameter-planning绑定已定义的规则及必要分支。
如进入时有其他尾液，不直接套片段：计入总容量和最终排空量，明确其来源/归宿。push_out按统一条件/明确覆盖判断。是否弃头由当前流程决定。
