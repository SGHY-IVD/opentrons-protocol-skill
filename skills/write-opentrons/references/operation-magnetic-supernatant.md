# 磁吸后全量去上清策略

按下节适用范围命中时读取；模块承载与条件按[模块契约入口](api-modules.md)定位，通用液量、路径和活塞状态见[操作规则](operations.md)。

## 磁吸后去上清

适用：孔板已位于Flex磁力架上、已按本次实验完成磁分离，本步骤将当前待去除上清全量送往指定废液位置。命中时采用本策略；用户明确覆盖按其范围优先。保留上清作后续样品、重悬及其他普通移液不自动套用。来源：用户2026-11-04确认的场景策略，未作本项目实机验证。

|阶段|吸液位置|正式运行吸液流速|局部动作|
|---|---|---|---|
|普通段|沿用本次常规固定吸液高度，默认bottom(0.8)|20µL/s|首次入液及每次吸后等待仍查delays|
|低位段|bottom(0.1)|10µL/s|从普通高度移至低位、低位吸后回升普通高度均用2mm/s；低位就位稳定等待0.2s|

上述流速仅覆盖本场景正式运行的吸液，不修改通用曲线或废液排速。dry_run按rates既有水相查速规则以各次实际吸排量取值；本次明确要求两种运行共用场景速度时才覆盖该分支。移动与等待按本策略及delays处理，不因试跑自动改变。

分批以源孔剩余待移除量V判断，每批从空枪头开始。有效容量C按本次枪头及移液器模式确定；以下默认保留最后20µL为一次完整低位吸液，须先核对C及量程支持该段。每批普通段量B=min(C, max(V−20, 0))；普通段后余量V′=V−B。仅当0<V′≤20且B+V′≤C时，本批低位吸V′；否则本批不做低位吸液，先把B按已定流程排入废液，再以更新的V′安排下一批。初始0<V≤20时跳过普通段、直接低位吸实际量；V=0不生成移液动作。两段均按每通道量，零量阶段跳过；不在每批重新扣留20，也不先吸满跨入源孔最后20的低位预算，不将最后20分散到两批凑满枪头。

按[参数化指引的预检时机](parameter-planning.md#计算与执行边界)核对全部批次：输入有限且非负、各非零段满足本次最小操作量、同批累计不超C、源孔液量及废液接收容量守恒。分段低于下限时报告具体段及配置，不擅改20或自动换模式凑量。已有枪头余液/空气、明确保留终液量或容量不足以容纳完整低位段时，先按实际需求另定合法方案，不直接套空头全量移除公式。

普通段进入前，仍按本次待准备状态在源top、空枪头时准备；同批普通段与低位段之间不退出、不prepare、不切模式。普通段存在时执行首次入液等待及普通吸后等待，再低位就位等待；低位吸后保留正常吸后等待。仅低位一段时，先按实际路径受控进入低位，该次首次入液等待与同位置低位稳定要求用一次停留满足，取两者较大值，不机械叠加。低位吸后先以局部速度回到普通高度，再按原受控退出速度到源top，适用的retract等待仍在实际退出后执行。批间须实际排废至头空；下一批到源top检查准备需求，无新待准备事件不重复复位。废液排速、位置、push_out及处理枪头继续按原规则，不由本策略新增吹空、二段排液或带液弃头。

固定高度路径仍核对实际孔板、枪头可达性、第一段全程浸没及磁珠沉积分布；保留20µL不证明所有孔型在普通高度仍可吸液，0.1mm也不证明能吸净或避开磁珠。磁力架弹性支撑不替代这些检查。不凭模块名称猜XY避珠方向；缺口按原定位规则处理，不静默改高度或把程序终态0当作物理无残液。纯固定路径不额外要求体积模型；初始化和液量账本仍保留。

实现可按输入规模生成定值、批次表或必要计算，不强制函数或通用状态机。参考[单批片段](patterns-magnetic-supernatant.md#磁吸后去上清单批吸液)及[磁力架操作示例](module-practices-magnetic-block.md#磁吸后去上清操作示例)；它们只实例化本条，不维护第二套默认。
