# 长孵育等待与进度提示

仅在长孵育使用阻塞delay时读取。本页只维护孵育分段策略，吸排液短等待仍查[delays](delays.md)，模块接口与原生等待按对应模块契约。

## 长孵育分段提示

长孵育使用阻塞delay时，默认按每段最多5分钟等待，每段结束用简短comment提示累计等待量/本次总时长；末段只等待余时。先按正式运行、dry_run及本次用户覆盖选择实际采用的总时长，再分段，累计量、提示分母和余时均用该时长，不沿用另一分支或示例的固定时长。短于一段只等待实际时长，0秒不生成等待或虚假的完成提示；不另设通用dry_run缩短秒数。

这是用户2026-10-28确认的默认方式，可由本次明确要求覆盖；不额外增加pause，不拆分吸排液短等待，不自动改写模块原生hold、到温或并发Task等待。先满足本流程必要的到温/准备条件，再开始计所需孵育时间；保持原有温控状态与收尾。结构示例及分析期文案限制见[设备经验入口](device-experience.md)“长孵育分段提示”。
