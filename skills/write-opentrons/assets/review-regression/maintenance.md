# 审查回归维护

仅用于维护技能、验证审查能力，不是日常生成必读，不是官方模拟器或完整协议静态分析器。

## 文件与使用

- cases.json：独立题面；中性编号不泄露对错，包含范围、前置状态、用户覆盖、代码。
- expected.json：维护者固定答案；依据当前规则而不是根据审查输出倒改答案。规则改变时先审阅并修订相关答案，再测试；保留git历史。
- baseline-review.json / baseline-report.md：首次独立审查原始结果与评估记录，不能给后续审查者看。
- ../../scripts/review_regression.py：验证题库结构/Python语法，或对比结果类别与定位；不自动判断自然语言理由正确与否。
- test_flow_rate.py：维护时运行`python3 assets/review-regression/test_flow_rate.py`，独立核算曲线契约、内嵌纯函数及受控混匀/CSV数值桩；不依赖Git历史或SDK，不作协议模板或默认分支编排依据。
- test_mixing_modes.py：维护时运行`python3 assets/review-regression/test_mixing_modes.py`，核对默认dynamic、明确static覆盖及实际M/S/拆段取速率、液量及START/END语义，并执行混匀实例片段；受控模型只验证局部动作契约，不替代官方模拟或实机。
- test_magnetic_supernatant.py：维护时运行`python3 assets/review-regression/test_magnetic_supernatant.py`，执行当前原子片段的正常/用水分支及两组磁力架示例，核对末段预算、容量、准备、等待、排废和维护曲线；分批计划器仅为受控输入夹具，不是交付必需实现，不作几何或实机验证。

维护者先运行 `python scripts/review_regression.py`。随后让全新上下文的审查者只读取SKILL.md、所需references及cases.json；禁止提供答案、历史结果、维护者诊断或本文件。输出 `{ "results": [{"id":"R01", "status":"pass|issues|unresolved", "findings":[{"line":1,"reason":"具体原因与分支"}]}] }`。

审查完成后维护者执行 `python scripts/review_regression.py --results <结果路径>`。局部运行用 `--ids R01 R02 ...`，结果必须恰好覆盖选择的编号。脚本仅检查类别/行号；对照expected逐项人工核对理由、状态量、分支条件及建议是否符合规则。等价定位可人工接受但须记录理由，不能为获得绿灯修改答案。额外有效问题先修正题面歧义，不把所有额外发现当误报。结果信息不足、读取失败、无输出都不能算通过。

分类记录漏检、误报、定位/理由错误、正确识别未知；同时记录技能版本、模型/运行环境可得信息、覆盖编号、原始输出和人工核对结果。不杜撰不可得的模型标识；单次通过仅表示这批题本次通过，不代表100%审查准确或实机有效。

## 当前混匀覆盖与维护入口
